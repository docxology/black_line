# Black Line manuscript

This is the active source for *Black Line: Strong Work in Public*. Read the
numbered sections in order.

1. [Abstract](00_abstract.md)
2. [Introduction](01_introduction.md), [Line Set relationship](01b_line_set_relationship.md),
   and [scholarship](01c_scholarship.md)
3. [Method](02_method.md) and [review protocol](02b_protocol.md)
4. [Practice registry](03_practices.md) and [formalism](03b_formalism.md)
5. [Examples](04_examples.md)
6. [Limits](05_limits.md)
7. [Conclusion](06_conclusion.md)
8. [References](99_references.md)

[Configuration](config.yaml) sets metadata, geometry, figure sizing, and
render formats. [The preamble](preamble.md) provides the LaTeX supplements.
[The bibliography](references.bib) supplies the manuscript citations.
Figure links resolve into the generated `output/figures/` tree after building
the registry-driven plates.

Use the [pinned render workflow](../development.md#render-and-validate-the-manuscript)
to produce and validate the publication. See the [manuscript contract](AGENTS.md)
before editing formalism, captions, or derived claims.
