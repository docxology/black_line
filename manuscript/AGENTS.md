# Manuscript contract

Markdown sources for the Black Line instrument paper. Figures embed from
`output/figures/` via the figure registry generated by `black_line.figures`.

- `config.yaml` — title, authors, publication metadata, page geometry, and figure-occupancy fractions for template rendering.
- Section files (`01_*.md` …) — prose, equations, and figure references.
- Claim and symbol registries bind to executed source values; update tests in `tests/test_manuscript_bindings.py` when literals change.

Regenerate figures here, then re-render through the external template engine (<https://github.com/docxology/template>, cloned wherever you like) after changing captions, digest bindings, or analysis-derived numbers.
